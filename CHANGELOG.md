# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — 2026-11-23

Второй проход по проекту: сеть поднимается с нуля, награда за блок реально платится, пул платит воркерам, закрыты дыры, через которые можно было напечатать себе баланс.

### Исправлено

- Награда за блок не начислялась: адрес genesis-кошелька брался из `genesis.json` от старого деплоя. Теперь источник правды — сама цепь, файл создаётся и чинится автоматически.
- `QTR_NO_MINE=true` вешал ноду на интерактивном выборе кошелька.
- Пул не читал `.env` и запускался без адреса и ключа для выплат.
- `peers.json` в UTF-16 не парсился, а в коде был захардкожен адрес чужой ноды.
- `node_wallet.json` и `GENESIS_WALLET_BACKUP.json` писались в текущий каталог и могли попасть в коммит. Пути переведены на `__dirname`, файлы и остальные рантайм-данные добавлены в `.gitignore`.
- Сумма эмиссии на страницах показывалась как `1000.00M QTR` вместо `1.00B QTR`.
- `ecosystem.config.js` ссылался на `/root/...`; теперь пути считаются от каталога конфига.

### Безопасность

- `validateTx` пропускала транзакции с `from: SYSTEM | SYSTEM_FEE | REWARD`, поэтому через `/pool/add-tx` можно было начислить себе любой баланс. Системные транзакции теперь принимаются только из локального сборщика блока.
- `/block/push` и `/pool/submit-block` принимали блок без проверки транзакций. Добавлена валидация подписей, балансов, суммы награды, суммы комиссий и переиспользования nonce.
- P2P-цепь от пира принималась по структуре и PoW. Теперь обязательны совпадение genesis-хэша и полная проверка всех транзакций; сложность ограничена шагом пересчёта.
- Пул-эндпоинты без `QTR_POOL_API_KEY` были открыты всем. Теперь без ключа пускают только localhost.
- Повтор шары и повтор подписи с новым `id` больше не оплачиваются.
- XSS через `memo`, адреса и id в обозревателе, кошельке и rich list: всё из сети экранируется.
- `GET /search/%` ронял ноду необработанным `URIError`.
- Cookie сессии ставится сервером с `HttpOnly`; Chart.js и QR-библиотека лежат в `public/vendor` вместо CDN.
- Лимиты размера тела и таймауты на веб-прокси и пуле; rate limit на вход, регистрацию и переводы.
- `wallets.json`, `sessions.json` и `peers.json` пишутся атомарно; битый JSON не превращается в пустое состояние, а сохраняется как `.corrupt-<timestamp>`.
- Бот больше не хранит пароль пользователя в `bot_users.json`.
- Нода и пул по умолчанию слушают `127.0.0.1` (`QTR_BIND` меняет адрес).

### Добавлено

- GitHub Actions: синтаксис, запуск ноды, веба и пула, 30 API-тестов на Node 18/20/22.
- Шаблоны issue и PR, `CONTRIBUTING.md`, `SECURITY.md`, `docs/ARCHITECTURE.md`.
- MIT-лицензия.
- Скриншоты сняты с живой сети: статистика, статус, кошелёк, майнинг, обозреватель, очередь.

### Удалено

- `index.js` и `index_current.js` — старые копии Telegram-бота, которые никто не импортировал.

## [1.0.0] — 2026-11-22

Нода, майнер, пул, веб-кошелёк, P2P, Telegram-бот, TUI. Закрыт обход каталога в веб-сервере, добавлена проверка адреса получателя, файлы данных перенесены на `__dirname`, появился `test-api.js`.
