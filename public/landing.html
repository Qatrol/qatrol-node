◆ Вопросы

Часто
спрашивают

Нужна ли видеокарта или ASIC для майнинга? ▾
Нет. QTR майнится на обычном процессоре (CPU). Майнер использует все ядра CPU автоматически. Подойдёт любой ноутбук или ПК с Windows 10/11.
Как быстро приходят монеты после запуска? ▾
Пул распределяет выплаты каждые 5 минут пропорционально шарам. Уже через несколько минут после запуска майнера ты увидишь первые QTR на балансе.
Сколько QTR можно добыть? ▾
За каждый найденный блок пул получает 16.7 QTR и делит между активными майнерами пропорционально хэшрейту. Чем больше у тебя ядер CPU — тем больше доля. Сложность автоматически подстраивается под общий хэшрейт сети, целевое время блока — около 10 минут.
Майнер безопасен? Это не вирус? ▾
Майнер — это open-source Node.js приложение, собранное в .exe через pkg. Оно использует только CPU и HTTP для связи с пулом. Антивирусы иногда ложно реагируют на self-contained .exe файлы — это нормально для подобного ПО.
Когда QTR будет на бирже? ▾
Листинг запланирован на Q3–Q4 2026. Genesis-резерв (~380M QTR) будет использован для обеспечения ликвидности. Следи за новостями в Telegram канале.
Можно майнить с нескольких компьютеров на один адрес? ▾
Да. Просто запусти майнер на каждом ПК с одним и тем же адресом кошелька. Пул суммирует все шары от одного адреса и выплачивает пропорционально общему хэшрейту.
